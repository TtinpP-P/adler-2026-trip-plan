# Адлер 2026 — интерактивный план поездки

Адаптивный многостраничный план поездки на 1–8 августа 2026 года:

- маршрут по восьми дням;
- питание и логистика;
- каталог мероприятий;
- билеты и официальные кассы;
- практические адреса и Яндекс Карты;
- интерактивная смета;
- тёмная и светлая темы;
- мобильная адаптация для iPhone и Android;
- автономный HTML без внешних файлов.

## Публичный сайт

https://ttinpp-p.github.io/adler-2026-trip-plan/

GitHub Pages автоматически собирает и публикует полноценную многостраничную
версию после каждого изменения ветки `main`.

## Локальный запуск

```bash
npm install
npm run dev
```

## Автономный HTML

```bash
npm run export:html
```
